# Posts API

REST API for users, posts and comments. The React client is [posts-ui-react](https://github.com/olegcntu/posts-ui-react).

## Features

- CRUD for users, posts and comments
- PostgreSQL schema in `database.sql`
- Error handling

## Tech stack

Node.js, Express, PostgreSQL, node-postgres

## Getting started

Create the database from `database.sql`, set `DB_PASSWORD`, then:

```bash
npm install
npm start
```
